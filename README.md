# rezs

`rezs` is an integration project that vendors verified baselines of:

- [AgentTube / YouTube Automation Agent](https://github.com/darkzOGx/youtube-automation-agent)
- [MoneyPrinterTurbo](https://github.com/harry0703/MoneyPrinterTurbo)

The two upstream applications are currently present as an unchanged baseline. Integration and YouTube Shorts automation layers will be implemented incrementally in later phases; they are not part of this checkpoint.

See [`docs/BASELINE.md`](docs/BASELINE.md) for pinned commits, setup commands, runtime inventory, and validation results.
